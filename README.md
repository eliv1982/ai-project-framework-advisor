# ai-project-framework-advisor

Учебный проект (домашнее задание): консольный агент на LangChain, который по описанию
будущего ИИ-проекта рекомендует один из фреймворков — LangChain, LlamaIndex или Haystack —
с обоснованием, подходящими компонентами и рисками.

Статус: реализация в процессе, рабочий код пока не добавлен.
